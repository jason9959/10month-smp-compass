# Moving Average Backtest (Streamlit)

종가와 N개월 이동평균을 이용해 **주식 보유 ↔ 현금 보유**를 전환하고, 정기 적립까지 함께 시뮬레이션하는 Streamlit 백테스트 앱입니다.

## 전략 규칙

- 가격 데이터: `yfinance`의 수정 종가(Adjusted Close)
- 이동평균: `N개월 × 21거래일` 단순이동평균(SMA)
- 당일 종가 > SMA: BUY 시그널
- 당일 종가 < SMA: SELL 시그널
- 당일 종가 = SMA: NEUTRAL
- 신호 확정 시 **당일 종가로 체결**
- 소수점 주식 매수 허용
- 수수료, 세금, 환율, 현금 이자는 반영하지 않음

### 포지션 변경 확인 횟수 + 시그널 대기 LIMIT

포지션 변경은 `확인 횟수`와 `시그널 대기 LIMIT(거래일)`을 함께 사용합니다.

- CASH 상태에서는 BUY 시그널을 누적합니다.
- STOCK 상태에서는 SELL 시그널을 누적합니다.
- 목표 횟수에 도달하면 그날 종가로 즉시 포지션을 변경합니다.
- 같은 방향 시그널이 새로 들어올 때마다 LIMIT 대기 기간을 다시 시작합니다.
- LIMIT 동안 NEUTRAL이 나와도 누적 횟수는 유지됩니다.
- LIMIT이 끝날 때까지 다음 같은 방향 시그널이 오지 않으면, 목표 횟수를 덜 채웠더라도 그날 종가로 포지션을 변경합니다.
- LIMIT 전에 반대 방향 시그널이 나오면 누적 횟수와 LIMIT 상태를 모두 초기화합니다.
- 확인 횟수 = 1이면 기존 즉시 전환 방식과 동일합니다.

예: 확인 횟수 = 3, LIMIT = 5거래일

1. SELL 1회 → 최대 5거래일 동안 다음 SELL 대기
2. 그 안에 SELL 발생 → 2회로 증가하고 LIMIT 5거래일을 다시 시작
3. 그 안에 SELL 발생 → 3회 충족, 즉시 매도
4. 추가 SELL 없이 LIMIT 도달 → 현재 누적 횟수로 즉시 매도
5. LIMIT 전에 BUY 발생 → 모든 SELL 누적 상태 초기화

백테스트 시작 시 포지션은 CASH이며, 초기 투자금도 동일한 확인/LIMIT 규칙을 적용합니다.

### 적립식 투자

선택 가능한 주기:

- 매주
- 매월
- 매분기
- 매반기
- 매년

첫 적립 예정일은 입력한 시작일에서 선택한 주기만큼 지난 날입니다.

예: 시작일 `2026-06-21`, 매월 적립

- 2026-07-21
- 2026-08-21
- 2026-09-21

예정일이 거래일이 아니라면 **그 이후 가장 가까운 거래일**에 실제 적립합니다. 실제 적립일이 밀리더라도 다음 예정일은 원래 시작일 기준 캘린더 스케줄을 유지합니다.

### 적립과 시그널 확인

적립금은 raw 시그널이 아니라 **실제 포지션**을 기준으로 처리합니다.

- CASH이고 BUY가 아직 확인 횟수에 도달하지 않음 → 현금 적립
- STOCK이고 SELL이 아직 확인 횟수에 도달하지 않음 → 적립금으로 추가 매수
- CASH → STOCK 확정일과 적립일이 같음 → 적립금을 현금에 먼저 더한 뒤 전액 매수
- STOCK → CASH 확정일과 적립일이 같음 → 주식을 먼저 전량 매도한 뒤 적립금을 현금에 추가

## 화면 구조

### 조건 입력 화면

사이드바를 사용하지 않고 메인 화면에서 아래 조건을 입력합니다.

- 티커
- 시작일 / 종료일
- 이동평균 개월 수
- 포지션 변경 확인 횟수
- 시그널 대기 LIMIT(거래일)
- 초기 투자금
- 적립식 사용 여부
- 적립금액
- 적립주기

기본 종료일은 **오늘(Asia/Seoul 기준)**, 기본 시작일은 오늘에서 **정확히 10년 전**입니다.

`백테스트 실행` 버튼을 누르면 결과 화면으로 이동합니다.

`입력값 초기화` 버튼은 최초 기본값으로 되돌립니다.

### 결과 화면

- 주요 성과 지표
- 가격 + 이동평균 + 실제 포지션 전환 지점 그래프
- 이동평균 전략 / 입력 티커 / 누적 납입금 비교 그래프
- 거래 및 적립 내역
- 예정 적립일 / 실제 적립일 확인
- 결과 PNG 저장
- 조건 입력 화면으로 돌아가기

두 번째 그래프의 Buy & Hold 비교선은 `Buy & Hold`가 아니라 사용자가 입력한 티커(예: `QQQ`)로 표시됩니다.

`← 조건으로 돌아가기`는 `page` 값만 변경하며, 입력 관련 `session_state`를 삭제하거나 초기화하지 않으므로 기존 입력 조건이 그대로 유지됩니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub → Streamlit Community Cloud 배포

1. 이 프로젝트 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Streamlit Community Cloud에서 새 앱을 만듭니다.
3. GitHub 저장소와 브랜치를 선택합니다.
4. Main file path를 `app.py`로 지정합니다.
5. Deploy 합니다.

별도의 API Key나 Secrets는 필요하지 않습니다.

## 금액 단위 주의

환율 변환 기능은 없습니다. 초기 투자금과 적립금은 **해당 종목의 가격과 동일한 통화 단위**로 계산됩니다.

예:

- QQQ: USD 단위로 해석
- 005930.KS: KRW 단위로 해석
