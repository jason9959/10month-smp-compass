# Moving Average Backtest (Streamlit)

종가와 N개월 이동평균을 이용해 **주식 보유 ↔ 현금 보유**를 전환하고, 정기 적립까지 함께 시뮬레이션하는 Streamlit 백테스트 앱입니다.

## v1 전략 규칙

- 가격 데이터: `yfinance`의 수정 종가(Adjusted Close)
- 이동평균: `N개월 × 21거래일` 단순이동평균(SMA)
- 당일 종가 > SMA: 주식 보유
- 당일 종가 < SMA: 현금 보유
- 당일 종가 = SMA: 기존 포지션 유지
- 신호가 발생한 **당일 종가로 체결**
- 소수점 주식 매수 허용
- 수수료, 세금, 환율, 현금 이자는 반영하지 않음

### 초기 투자금

백테스트의 실제 첫 거래일에 종가가 SMA 위라면 초기 투자금 전액을 매수하고, 아래라면 현금으로 보유합니다.

### 적립식 투자

선택 가능한 주기:

- 매주
- 매월
- 매분기
- 매반기
- 매년

첫 적립 예정일은 입력한 시작일에서 선택한 주기만큼 지난 날입니다.

예: 시작일 `2026-06-21`, 매월 적립

- 2026-07-21
- 2026-08-21
- 2026-09-21

예정일이 거래일이 아니라면 **그 이후 가장 가까운 거래일**에 실제 적립합니다. 실제 적립일이 밀리더라도 다음 예정일은 원래 시작일 기준 캘린더 스케줄을 유지합니다.

예:

- 예정일: 2026-07-21 → 실제 거래일이 없어 2026-07-23 실행
- 다음 예정일: 그대로 2026-08-21

월말 날짜(예: 1월 31일)는 `dateutil.relativedelta`를 사용해 각 월에서 가능한 날짜로 처리하며, 매번 원래 시작일을 기준으로 다음 예정일을 계산합니다.

### 적립일과 포지션 변경일이 같은 경우

- CASH → STOCK: 적립금을 현금잔고에 먼저 더한 뒤 전액 매수
- STOCK → CASH: 기존 주식을 먼저 전량 매도한 뒤 적립금을 현금잔고에 추가
- STOCK 유지: 적립금으로 추가 매수
- CASH 유지: 적립금만 현금으로 보유

## 화면 구조

### 조건 입력 화면

사이드바를 사용하지 않고 메인 화면에서 아래 조건을 입력합니다.

- 티커
- 시작일 / 종료일
- 이동평균 개월 수
- 초기 투자금
- 적립식 사용 여부
- 적립금액
- 적립주기

`백테스트 실행` 버튼을 누르면 결과 화면으로 이동합니다.

`입력값 초기화` 버튼은 최초 기본값으로 되돌립니다.

### 결과 화면

- 주요 성과 지표
- 가격 + 이동평균 + 포지션 전환 지점 그래프
- 이동평균 전략 / Buy & Hold / 누적 납입금 비교 그래프
- 거래 및 적립 내역
- 예정 적립일 / 실제 적립일 확인
- 결과 PNG 저장
- 조건 입력 화면으로 돌아가기

`← 조건으로 돌아가기`를 누르면 기존 입력 조건이 그대로 유지됩니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub → Streamlit Community Cloud 배포

1. 이 프로젝트 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Streamlit Community Cloud에서 새 앱을 만듭니다.
3. GitHub 저장소와 브랜치를 선택합니다.
4. Main file path를 `app.py`로 지정합니다.
5. Deploy 합니다.

별도의 API Key나 Secrets는 필요하지 않습니다.

## 금액 단위 주의

v1에는 환율 변환 기능이 없습니다. 초기 투자금과 적립금은 **해당 종목의 가격과 동일한 통화 단위**로 계산됩니다.

예:

- QQQ: USD 단위로 해석
- 005930.KS: KRW 단위로 해석

금액의 절대 단위보다 전략의 수익률이나 상대 비교만 확인할 목적이라면 임의의 동일 단위를 사용해도 됩니다.
